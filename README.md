# 小小世界

給小朋友玩的小小世界：捏幾個積木小人，在看得到店內的商店街逛街，把人拖到東西上就會互動。玩家還不識字，介面全部用圖示和色塊。

線上玩：<https://tsun-u.github.io/tsunu-tinytown/>。可以安裝成 APP：Android 的 Chrome 選單選「加到主畫面」或「安裝應用程式」，iPad 的 Safari 按分享再選「加入主畫面」；裝好後從圖示開，畫面沒有網址列。安裝版還是要連網才開得起來。

街上有七棟可以進去的房子（醫院、百貨公司、點心店、牙醫診所、家、玩具店、幼稚園），還有會開的小車、天氣和時間。

## 怎麼開

```
python serve.py
```

瀏覽器開 `http://127.0.0.1:8798/`。要讓同一個區網的平板試玩，改成 `python serve.py <這台電腦的區網 IP> 8798`。`serve.py` 只送遊戲本身的檔案（`index.html`、`styles.css`、`savebox.js`、`src/`、`vendor/`）。不用建置，three.js 放在 `vendor/`（0.187.0，MIT）。

## 更新與版本號

瀏覽器會把檔案留一段時間（GitHub Pages 是 10 分鐘），所以 `index.html` 開啟時先讀 `version.txt`（不走快取），再用裡面的版本號去拿樣式和 `src/` 的每個檔案，更新後才不會拿到舊檔或新舊混用。

- `version.txt` 由 `.git/hooks/pre-commit` 在每次 commit 時自動換成當下的時間。hook 不進版控，重新 clone 後要補上：內容是 `date +%Y%m%d-%H%M%S > version.txt` 和 `git add version.txt` 兩行。
- `src/` 新增檔案時，加進 `index.html` 的 `MODULES`。
- `index.html`、`savebox.js`、`vendor/` 沒有版本號，改了以後最多 10 分鐘才生效。

## 怎麼玩

- 拖小人：放到椅子上會坐下，放到另一個人旁邊會打招呼，放到地上就站在那裡。
- 街道是 L 型：左邊一排由近到轉角是醫院、停車塔、百貨公司、點心店，後面一排由轉角往右是牙醫診所、家、玩具攤、寵物店、幼稚園；轉角是小公園，有噴水池和一張可以坐兩個人的長椅。
- 換地方：街道是中心。在街上把小人拖到某一棟門口的藍色圈圈，他就進那一棟（現在能進的是醫院、點心店、家、玩具店）；在屋裡把他拖到門口，就回到街上那一棟的門外。畫面會跟著被拖的人走。
- 地圖：左上角的鈕隨時都在，畫的是現在在哪裡；點開是所有地方的圖示，圖示旁的小頭像是現在在那裡的人，點哪個畫面就切過去。只切換畫面，不帶人。
- 睡覺：在家把小人拖到床上會躺下。雙人床躺兩個人，旁邊的小床躺一個人。
- 泳池：在家的院子把小人拖進泳池，他會坐在水裡拍水、濺水花，可以坐兩個人。
- 煮東西：在家把小人拖到爐子前面，他會攪鍋子、鍋子冒蒸氣，3 秒後煮好，餐桌上吃空的盤子馬上補滿；點一下站在爐子前的人可以再煮一次。
- 洗東西：拖到水槽前面，水龍頭會流水、水槽冒泡泡，3 秒後洗好跳一下。
- 開冰箱：拖到冰箱門邊，冰箱門會打開、看得到裡面的食物，拿出一支三色冰棒後轉過身來吃。點一下站在水槽、冰箱前的人可以再做一次。
- 玩具店：拖到搖搖馬會騎上去前後搖，拖到球池會坐進球裡，積木桌旁有四張小凳子。
- 醫院（街上最左邊的高樓，兩層）：一樓有掛號櫃台、候診椅、看診桌、診療床；拖到長頸鹿身高尺上，橫桿會降到頭頂。二樓是病房，有三張病床、訪客沙發、輪椅。
- 輪椅：醫院有兩台，一樓和二樓各一台。把小人拖到輪椅上會坐下。拖坐在輪椅上的人，輪椅會跟著一起走（只在地板上走，朝推的方向轉）；推到床或沙發上放手，人就換坐過去、輪椅停在旁邊；點一下坐輪椅的人，他會站起來。推到電梯門口，連輪椅一起搭到另一層；推到通往街上的門，人自己走出去、輪椅留在醫院。輪椅停在哪一層、哪個位置會存檔。
- 換樓層：把小人拖到電梯門口的藍色圈圈，他就搭到另一層；拖近時電梯門會打開。地圖選單裡每一層是一格，圖示上有樓層數字。
- 百貨公司（左邊第二棟高樓，四層）用手扶梯，一次走一層：靠後牆、有綠色往上箭頭的那台往上，地板開口裡、有橘色往下箭頭的那台往下，拖到入口的藍色圈圈就搭。
  - 地下室超市：兩台購物車可以坐進去。
  - 一樓服飾店：拖進試衣間，簾子會拉上，出來換一套不同顏色的上衣和褲裙；右邊有兩張沙發凳。
  - 二樓遊戲區和書店：火箭和小車兩台搖搖車、彈跳床（站上去一直跳）、夾娃娃機、兩顆懶骨頭。
  - 三樓美食街：冰淇淋攤前面拿一支冰棒，麵攤前面點餐（煮好時桌上吃空的盤子補滿），兩張桌子可以坐下吃蛋糕。
- 左上角三顆鈕（照線稿的順序）：天氣、時間、地圖。圖示畫的是現在的狀態，點了從鈕的下面展開選項。
  - 天氣：晴天、下雨、下雪。雨和雪只下在屋外（院子、人行道、陽台、屋子四周），屋裡不會下；地下室超市看不到雨雪。
  - 時間：早上、中午、傍晚、晚上；光線、影子的方向和背景顏色會跟著變，晚上背景有星星，燈泡和路燈會顯得特別亮。晚上屋裡會開燈：屋內是暖黃色的光，院子維持夜晚的藍色。
  - 天氣和時間會存檔。
- 小車：街上的粉紅敞篷車有前座和後座。把小人拖上車，車子就沿著馬路繞圈開（街尾迴轉）；車上的人都下車，車子就停在原地。
- 停車塔（醫院和百貨公司中間，三層，第三層露天）：
  - 開進去：把坐在街上車裡的人拖到停車塔門口，整台車連同車上其他人一起開進一樓。走路的人拖到門口是自己走進去。
  - 塔裡本來就停著三台車（藍色在一樓、黃色在二樓、綠色在三樓），拖到車上就坐進去。
  - 在塔裡開車：拖坐在車上的人，車子跟著走；點一下車上的人，他會下車。
  - 換樓層：把車（或走路的人）拖到坡道口的藍色圈圈。綠色箭頭的坡道往上，橘色箭頭的開口往下。
  - 開出去：在一樓把車拖到前面黃黑線外的藍色圈圈，車就開到街上。四台車都可以開上街。
  - 車子停在哪一層、哪個位置會存檔。
- 幼稚園（街尾黃屋頂那一棟）：教室裡有點心桌（可以吃蛋糕）、畫畫桌、兩張午睡墊、鋼琴（拖到琴鍵前面會彈，飄出音符）；門外的小公園有溜滑梯（坐上去會一直溜）、兩座鞦韆、沙坑、兩匹搖搖馬。
- 牙醫診所（街上有臉的那一棟，嘴巴是門口）：兩張診療椅可以躺，躺上去頭頂的燈會亮、牙齒冒星星；拖到大牙齒旁邊會幫它刷牙、冒泡泡；左牆有兩張候診椅。
- 小東西：有些小物品可以用手指拖（玩具店桌上的三塊積木和小熊、醫院看診桌上的聽診器和針筒、超市的蘋果、香蕉和西瓜、幼稚園桌上的兩本書）。
  - 拖到人身上，他就舉在左手上拿著，帶到哪裡都跟著；狗狗用嘴巴叼。一個人一次拿一樣，再給他別的，原本那樣會放到腳邊。
  - 放下：把他手上的東西拖走，放到桌面（每樣東西一開始放的位置）或地上；或是點一下拿著東西的人，東西會放到他腳邊。
  - 拿著東西的人被拖去跟朋友打招呼，朋友空著手的話會把東西遞給他。
  - 東西在哪裡、被誰拿著會存檔。刪掉拿著東西的人，東西回到原本的位置。
- 寵物店（玩具攤和幼稚園中間、屋頂有一根大骨頭的那一棟）：泡泡澡盆可以坐進去拍水；美容桌上躺一個、旁邊站一個幫他刷毛、冒泡泡；兩張寵物睡墊可以躺。店裡有一隻店狗和一位店員，後面有貓跳台、兔子圍欄和魚缸。
- 醫生、護理師、店員、老師、寵物店的店狗是固定角色：跟玩家的小人一樣可以拖、可以坐、可以搭電梯和手扶梯、可以進出每一棟，位置會存檔。他們不會出現在造型面板和地圖選單的頭像裡，不能改造型也不能刪。
- 吃蛋糕：坐到桌邊的椅子，面前有蛋糕就會吃，三口吃完；盤子空了 6 秒後補一盤，點一下坐著的人可以再吃。
- 轉鏡頭：兩指左右拖，滑鼠用中鍵拖。店只有兩面牆，所以只能往左右各轉一段（約 43 度；超過 45 度牆會跑到鏡頭前面）。在街上轉到底，可以正面看左邊那一排或後面那一排。
- 放大縮小：兩指捏合，滑鼠用滾輪；會朝手指或游標的位置放大，最多 3 倍，縮到底回到全景。
- 點右上角的大頭照開造型面板：上面一排選要改誰、加人（最多 6 個）、刪人（垃圾桶按兩下）；下面每一排是一種造型。
- 狗狗：造型面板第一排可以選大人、小孩或狗狗。選了狗狗，下面換成狗狗的幾排：毛色、耳朵（垂耳、立耳）、斑塊（沒有、眼睛、背上）、項圈顏色。狗狗跟人一樣可以拖去每個地方：坐椅子、騎東西、睡覺都是趴著，泳池裡會拍水，拿到冰棒會叼在嘴裡。換回人的時候，原本的造型還在。
- 面板開著時點小人，會換成改那個人。

## 測試入口

- `?fresh=1`：不讀存檔，用預設的兩個人。
- `?shadows=0`：關掉即時陰影，改用腳下的假影子（平板跑不順時的退路）。
- `?panel=creator`：一開頁就打開造型面板。
- `?person=<id>`：一開頁選中這個人。
- `?place=home`、`shop` 或 `toys`：一開頁到那個地方（選中的人在別的地方時，畫面會跟著那個人）。
- `window.__town`：`people`、`places`（已經蓋好的地方；第一次用到才蓋）、`world`（現在這個地方的座位、障礙、可站範圍、門口）、`placeName`、`goTo(name)`、`creator`、`renderer`、`frames`（格數與最長的一格）、`select(person)`、`sky`（`sky.set({ time, weather })` 直接換時段和天氣）、`getYaw()` 和 `setYaw(角度)`（鏡頭角度）、`look`（縮放倍率與平移）、`screenOf(x, y, z)`（世界座標換成畫面座標）。

存檔在 localStorage 的 `tinytown.v1`。造型面板右上角的 💾 可以把存檔匯出成檔案、再匯入回來（`savebox.js`，跟釣魚日、醫院一二代、IT24hr 同一份，內容要保持完全相同）；新增存檔項目時要加進 `SaveBox.init` 的 `keys`。測試用隔離的瀏覽器分頁，不會動到自己的存檔。

## 檔案

- `src/main.js`：場景、鏡頭、拖曳、存檔。
- `src/shop.js`：店和街道的模型，以及座位、障礙、可站範圍；牆、椅子、桌子這些兩個地方共用的零件也在這裡。
- `src/home.js`：家和院子的模型。
- `src/toys.js`：玩具店的模型；搖搖馬是獨立的網格，有人騎才會搖。
- `src/hospital.js`：醫院一樓（`hospital`）和二樓（`hospital2`）的模型。有樓層的大樓一層是一個地方，電梯是通往另一層的門口；電梯門板、身高尺的橫桿、輪椅是獨立的網格。座位資料帶 `mobile: true` 的（輪椅）可以連人一起拖：做法見下面「載具」那一條。
- `src/dept.js`：百貨公司四層（`dept0` 地下室到 `dept3` 三樓）。`finishFloor` 替每一層加上往上、往下的手扶梯門口和到達位置；階梯、試衣間的簾子、搖搖車是獨立的網格。
- `src/kinder.js`：幼稚園的教室和小公園。鞦韆、搖搖馬是獨立的網格；溜滑梯的座位帶著滑道頂端和底部的位置，主程式照著移動坐在上面的人。
- `src/dentist.js`：牙醫診所。診療椅的燈和星星、刷牙的泡泡是獨立的網格。
- `src/items.js`：可以拿的小東西的名單（一開始放哪裡）和模型。主程式的「小物品」那一段管拖曳、拿、放和存檔；人怎麼拿在 `person.js` 的 `carry`、`release`（換造型時身體整個重建，手上的東西會接回去）。
- `src/parking.js`：停車塔三層（`park1` 到 `park3`）。
- 載具（主程式的 `gatherVehicles`、`moveVehicle`、`travel`）：輪椅和車子是同一套。座位資料帶 `mobile: true`，同一台的位子用 `wheel` 或 `car` 編號收成一台；同一台載具在它去得了的每個地方都留了位子，不在那裡時是 `away`，過門口時這邊收起來、那邊擺出來，車上的人一起過去。街上的車不用拖，自己沿車道開（`street.js` 的 `driveCars`）。
- `src/pets.js`：寵物店。澡盆的水花、刷毛的泡泡是獨立的網格。
- 街道的版面有編號（`street.js` 的 `STREET_LAYOUT`，存檔的 `layout`；1 是一條直街、2 是加了停車塔和寵物店的直街、3 是 L 型）：版面一改，站在街上的人和放在街上的小東西要跟著旁邊的房子移，`migrateStreetSpot` 把舊版面的位置換算成新的，主程式在開頁時套用。街上的車開到哪裡（`s`）換版面後不算數，只留它在不在街上。
- 街上每一棟的函式用的是「一整排往右排、正面朝前」的座標；後排整棟平移，左排整組轉 90 度（`toArm`）。車道是一圈折線取樣成的點（`LANE_POINTS`）。每個地方的座位只能加在名單最後面，存檔記的是第幾個座位。
- `src/sky.js`：時段（光線、背景顏色）、天氣（雨、雪的粒子）和晚上屋裡的燈。每個地方的 `indoor` 是屋內範圍（`shop.js` 的 `ROOM`，街道是 null），雨雪照它藏掉會疊在屋內的部分；`underground` 的地方沒有雨雪。
- `src/staff.js`：固定角色的名單（一開始在哪裡、面向、制服）。他們跟玩家的小人放在同一個 `people` 陣列，`data.npc` 是 true；存檔只記位置，制服每次開頁照名單。制服配件（護士帽、聽診器、廚師帽、圍裙）在 `person.js`。
- 開頁只蓋街道和畫面所在的地方；人在還沒蓋的地方時先不就位，等那個地方第一次蓋好才放上去（`placeNamed`）。
- `src/street.js`：街道的模型：一排房子的外觀、人行道、馬路，以及每一棟的門口通往哪裡。
- `src/builder.js`：把整間店的幾何形狀合成一個網格。
- `src/person.js`：積木小人的模型與動作。狗狗也在這裡（`design.size` 是 `dog`）：`buildDog` 拼模型、`updateDog` 擺姿勢，主程式不用分人和狗。
- `src/design.js`：造型選項與 2D 頭像。
- `src/creator.js`：造型面板。
